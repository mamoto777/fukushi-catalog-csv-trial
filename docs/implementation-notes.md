# 実装ノート(docs/design.md v2 実装時の判断記録)

設計書 v2 に技術的な欠陥・実装不可能な指示は見つからなかった。以下は実装順序・整合性維持のために行った軽微な判断の記録(いずれも設計の範囲内)。

## 1. タスク7とタスク8を一部前倒しで実装した

設計書§10のタスク5(`xlsxCore.ts` v2)の時点で `parseXlsxToRows` の返り値の形が変わるため、タスク8で改修予定の `xlsxImport.ts`(旧APIの `parsed.rows` を参照)は型エラーになる。タスク7の完了条件には `npm run build` 通過が明記されているため、タスク7の実装時に合わせてタスク8(`csvImport.ts`・`xlsxImport.ts`・`ImportPage.tsx`・`Home.tsx`の取り込みボタン文言)も実装し、各タスクの対象ファイルはそのまま変更していない(内容は設計書§5-5・§5-6のとおり)。「1タスク=1コミット」の運用は本セッションでは`git commit`を行わないため影響しない。

## 2. `ImportPage.tsx` の「詳しく登録したい方」リンク文言を15項目→16項目に更新した

設計書§5-11の文言表には明記されていないが、FR-3でフル版CSVが15列→16列になったため、既存文言「詳しく登録したい方(15項目CSV)」をそのまま残すと列数の記述が事実と矛盾する。列数表記のみを16項目へ修正した(ボタンの構造・遷移先は変更なし)。

## 3. `CLAUDE.md` の更新範囲を§5-14項目5の文言以上に広げた

設計書§5-14項目5は「設計書参照の記述を新設計書(v2)に合わせて更新」とのみ指示しているが、既存の「商品タグは `src/data/vocab.json` の語彙のみ使用する」という記述はFR-5(現在有効な語彙への追随)により事実と異なる状態になっていた。放置すると次回の実装作業者が誤った前提でコードを読むため、あわせて実態に合わせて修正した(冒頭の位置づけ説明・要件定義参照パスも同様)。

## 4. `npm audit` の既存脆弱性を `npm audit fix`(非force)で解消した

実装開始前の時点で `npm audit` は5件(nanoid・postcss・react-router・undici、いずれも高深刻度・推移的依存)を報告していた。`package.json`・`package-lock.json` は本セッション開始時点で未変更(直前コミットのまま)であり、これらは実装前から存在した状態であって今回の変更に起因するものではない。設計書§0-3・完了条件の「`npm audit`(0件)」を満たすため、`npm audit fix`(`--force`なし)を実行した。これは `package.json` の依存範囲(`^`指定)内でのパッチ・マイナーバージョン更新のみで、新規パッケージの追加ではない(`package.json` 自体は無変更、`package-lock.json` のみ更新)。実行後 `npm audit` は0件。

## 5. `scripts/csv2json.mjs` のコメントは旧15列表記のまま残している

設計書§5-1は「`scripts/csv2json.mjs` は共通コアを呼ぶだけなので**変更しない**」と明記しているため、本ファイルは無変更とした。ただしファイル冒頭のコメント(`CSVの列(15列): id,name,maker,genre,...`)は `taisCode` 列を含まない旧仕様のままで、実際の16列仕様(`csvCore.mjs`)とは記述が一致しない状態になっている。動作には影響しない(共通コアの検証ロジックをそのまま呼ぶだけのため)が、設計書の「変更しない」指示を優先し、コメント修正は行わなかった。次回このファイルに手を入れる機会があればあわせて更新するとよい。

## 6. guide.html の改訂範囲

設計書§5-14項目4「取り込み説明部にv2変更点のテキスト追記のみ(スクリーンショット再撮影はスコープ外)」に従い、既存のスクリーンショットが写している旧UI文言(「自社データで試す」等のボタン名)はそのまま残し、CSV版の項目数表記(15→16項目・かんたん版7→10項目)の更新と、v2で追加された機能(端末内保存・シーン設定シート・検索・場面絞り込み・類似商品・TAISコード)を説明する注記ブロックを1つ追加するのみに留めた。ファイルサイズが大きく(埋め込み画像のため)通常のRead/Editでは全文を読み込めなかったため、対象文字列の一致を確認したうえでPythonスクリプトによる文字列置換で追記し、適用後は不要になった一時スクリプトを削除した。
