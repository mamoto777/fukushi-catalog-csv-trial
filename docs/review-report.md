## 3. 未修正の指摘事項(いずれも軽微・人間判断)

1. **`scripts/csv2json.mjs` の冒頭コメントが旧15列表記のまま**: 設計書§5-1「変更しない」指示を優先した実装者判断(実装ノート#5)を支持し、レビューでも触れなかった。動作影響なし。次回このファイルを触る機会に更新推奨
2. **`demo-products-100.csv`(リポジトリ直下・git未追跡)が旧15列形式**: 本セッション以前から存在する未追跡ファイルで、今回の実装範囲外。v2アプリに読み込ませるとヘッダ不一致エラーで拒否される(実害はエラー表示のみ)。デモ用サンプルとして残すなら16列で再生成、不要なら削除を人間判断で
3. **sceneCore の「有効行0件」エラーは、行エラーが1件でもあると出力されない**(`sceneMap.size === 0 && errors.length === 0` のガード): 設計§5-3の字義どおりなら無条件で追加とも読めるが、行エラーが表示されていれば0件エラーの併記は冗長であり、どちらにせよ取り込みは拒否される。挙動として妥当と判断し未修正(テストもこの挙動を検証してパス)

## 設計へのフィードバック
