# 機能一覧

**最終更新**: 2026-07-12(実装完了時点)

## 実装済み(デモ版 v1.0)

| 機能 | 内容 |
|---|---|
| ホーム | 2大ボタン(困りごとから探す/ジャンルから探す) |
| 困りごとナビ | 3問・1問1画面。質問3は場面に応じて動的表示、最大3つ複数選択 |
| タグマッチング | スコア式(困りごと×3+場面×2+利用者×1)。3件未満で場面一致まで自動拡張、0件でEmptyState |
| ジャンル一覧 | 9ジャンルのカードグリッド(スマホ2列/タブレット3列) |
| 商品リスト | マッチ度バッジ(ぴったり/おすすめ/ちかい商品)、並べ替え(おすすめ/安い/高い)、絞り込み(価格帯・保険区分) |
| 該当0件時 | 「条件をひろげて再検索」(困りごと条件を外し場面一致で再表示)/絞り込みリセット/ジャンル導線 |
| 商品詳細 | 価格(1割負担額の自動計算つき)・説明・こんな方におすすめ・仕様表・注意点 |
| 価格表示 | レンタル月額/特定福祉用具販売/保険適用外の3区分。負担割合2〜3割の注記 |
| 仮想100商品 | 9ジャンル・架空メーカー8社。全困りごと語彙をカバー(どの選択でも0件にならない) |
| 高齢者向けUX | 本文18px・ボタン20px・タップ領域48px以上・高コントラスト・フォーカス可視化・大型「もどる」 |
| 免責表示 | 全画面フッターに常時表示 |
| PWA | ホーム画面に追加可・オフライン閲覧可(cache-first) |
| データ更新 | CSV→JSON変換スクリプト(スキーマ検証・語彙チェック・行番号つきエラー) |
| 自動デプロイ | GitHub Actions(テスト→ビルド→GitHub Pages) |

## Phase 2(未実装・今後の拡張候補)

- 商品比較機能(設計時にPhase 2送りと決定)
- 商品ごとの個別画像(現状はジャンル共通イラスト)
- 検索キーワード入力(現状は選択式のみ)
- お気に入り・提案リストの印刷/共有
- 実データ移行(CSV変換スクリプトは同梱済み)

## 既知の制限

- 商品データ・価格・メーカーはすべて架空(デモ用)
- ナビの回答は保存されない(画面を戻ると再入力。個人情報非収集の仕様による意図的な制限)
- 商品画像はジャンル共通のイラスト9種を流用
- オフラインキャッシュは一度表示した後に有効(初回表示はネット接続が必要)
- 対応ブラウザ: 現行のiOS Safari / Android Chrome(古いブラウザは非対応)
