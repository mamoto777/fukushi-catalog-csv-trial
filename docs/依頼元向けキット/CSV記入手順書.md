# CSV記入手順書

自社の商品データをアプリに読み込ませて、テストプレイができるようにするための手順です。専門知識がなくても進められるように書いています。

> **まずはかんたん版がおすすめです**。Excelのプルダウンから選ぶだけで記入でき、形式変換も不要な「かんたん版」を先に試すことをおすすめします。詳しくは `かんたん版記入手順書.md` をご覧ください。メーカー名や詳しい説明・保険区分・仕様まで作り込みたくなったら、本書(フル版・15項目CSV)に進んでください。

---

## ① ひな形CSVをダウンロードする

アプリのホーム画面で「自社データで試す」を選び、「ひな形CSVをダウンロード」をタップ(クリック)してください。`products-template.csv` というファイルがダウンロードされます。

このファイルには、記入例として仮の商品データが3件(p001〜p003)入っています。まずはこの例を見て、どんな内容をどこに書けばよいかを確認してください。

## ② Excelで開く

ダウンロードした `products-template.csv` をダブルクリックして開いてください。Excelが自動で起動します。

## ③ 記入ルール

1行目は見出し(列の名前)なので変更しないでください。2行目以降に、1商品につき1行で記入します。列は全部で15列あります。

| 列名 | 内容 | 記入例 |
|---|---|---|
| id | 商品ID。`p001`のように「p+数字3桁」の形式。重複不可 | p004 |
| name | 商品名 | らくらく歩行器 |
| maker | メーカー名 | ○○福祉機器 |
| genre | ジャンル(下記「タグ語彙一覧.md」の9種類から1つ) | walking |
| price | 価格(税込・半角数字のみ) | 3000 |
| insurance | 保険区分。`rental`(レンタル)/`purchase`(販売・介護保険対象)/`none`(保険対象外) | rental |
| summary | 一覧に出る短い説明(1行) | 軽くて押しやすい歩行器 |
| description | 詳しい説明(3〜5行程度) | (自由記述) |
| specs | 仕様。「項目名:値」を「\|」でつなぐ | 重さ:3kg\|高さ調節:71〜94cm |
| recommendFor | 「こんな方におすすめ」を「\|」区切りで2〜4個 | 長い距離が不安な方\|外出が多い方 |
| caution | 注意点(1〜2行) | (自由記述) |
| concernTags | 困りごとタグ。「タグ語彙一覧.md」の語彙から「\|」区切りで1つ以上 | ふらつく・転びやすい |
| sceneTags | 場面タグ。同上の語彙から「\|」区切りで1つ以上 | 歩く・移動 |
| userTags | 利用者タグ。「本人が使う」「家族の介護に使う」を「\|」区切りで1つ以上 | 本人が使う |
| popularity | 並び順に使う人気度。1〜5の整数(5が一番上に出やすい) | 3 |

**注意点**

- `concernTags` / `sceneTags` / `userTags` は「タグ語彙一覧.md」に載っている言葉と**一字一句そのまま**でなければ読み込みエラーになります(自由な言い回しは使えません)
- カンマ「,」や改行を含む文章を書く場合は、そのセルを引用符(`"..."`)で囲んでください。Excelで通常通りセルに入力・改行すれば自動的にこの形式で保存されます
- 商品数は最大1,000件までです

## ④ 保存する

記入が終わったら、Excelの「名前を付けて保存」で、ファイルの種類を**「CSV UTF-8(コンマ区切り)」**に指定して保存してください。

(通常の「CSV(コンマ区切り)」形式で保存してもアプリ側で文字コードを自動判定しますが、文字化けの可能性を減らすため「CSV UTF-8」を推奨します)

## ⑤ アプリに読み込む

アプリのホーム画面で「自社データで試す」→「CSVファイルを選ぶ」から、保存したファイルを選択してください。正しく読み込めると「◯件の商品データを読み込みました」と表示され、そのままテストプレイできます。

読み込んだデータは**この端末のブラウザの中だけ**で使われ、どこにも送信・保存されません。画面をリロードすると自動的に元のデモデータに戻ります。

## ⑥ エラーが出たときの読み方

読み込みに失敗すると、「読み込めませんでした(データは変更されていません)」というメッセージと一緒に、エラーの一覧が行番号つきで表示されます。

例: `3行目: id "p1" は p001 形式ではありません`

これは「Excel上の3行目のデータに、指定した内容の誤りがある」という意味です。見出し行を1行目として数えるので、Excel上の行番号と一致します。該当行を直して、もう一度保存・読み込みをやり直してください。エラーが解消されるまで、元のデータ(デモまたは前回読み込んだデータ)はそのまま表示され続けるので、安心して直せます。
