# Copilot依頼文例

CSVの記入(タグ付け・整形)をCopilot(またはChatGPT等の対話AI)に手伝ってもらうときの定型文です。`[ ]` の部分をご自身の内容に置き換えてお使いください。「タグ語彙一覧.md」の表をコピーして貼り付けると精度が上がります。

---

## 例1: 困りごとタグ(concernTags)を選んでもらう

```
以下の商品説明に合う「困りごとタグ」を、次の一覧から2〜4個選んでください。
一覧にない言葉は使わず、選んだタグは「|」で区切って1行にまとめてください。

【商品説明】
[ここに商品の説明文を貼り付け]

【タグ一覧】
[タグ語彙一覧.mdの「困りごと」列をすべて貼り付け]
```

## 例2: 場面タグ(sceneTags)・利用者タグ(userTags)を選んでもらう

```
以下の商品が使われる「場面」を次の一覧から1〜2個、「利用者」を次の一覧から1〜2個選んでください。
それぞれ一覧にある言葉のみを使い、複数選ぶ場合は「|」で区切ってください。

【商品説明】
[ここに商品の説明文を貼り付け]

【場面の一覧】
歩く・移動 / 立つ・座る / 寝る・起きる / お風呂 / トイレ / 食事 / 見守り・その他

【利用者の一覧】
本人が使う / 家族の介護に使う
```

## 例3: 複数の値を「|」区切りに変換してもらう

```
次の箇条書きを、「|」(縦棒)で区切った1行のテキストに変換してください。
前後の空白は削り、余計な記号は付けないでください。

・[項目1]
・[項目2]
・[項目3]
```

## 例4: 仕様(specs)を「項目名:値」形式に整形してもらう

```
次の商品仕様を、「項目名:値」の形式にして、複数ある場合は「|」でつないで1行にしてください。
例: 重さ:490g|高さ調節:71〜94cm|材質:アルミ

【元の仕様メモ】
[ここに仕様の箇条書きやメモを貼り付け]
```

## 例5: 商品説明文(summary/description/caution)のたたき台を作ってもらう

```
以下の商品情報をもとに、次の3つの文章のたたき台を作ってください。
- summary: 一覧に出る短い説明(20字程度、1行)
- description: 詳しい説明(3〜5行程度、平易な言葉で)
- caution: 使用上の注意点(1〜2行)

【商品情報】
商品名: [ここに商品名]
特徴: [ここに特徴やメーカー資料の内容を貼り付け]
```
