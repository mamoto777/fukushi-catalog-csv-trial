# かんたん版記入手順書

自社の商品データをアプリに読み込ませて、テストプレイができるようにするための、一番かんたんな方法です。プルダウンから選ぶだけで記入できるので、専門知識がなくても進められます。

---

## かんたん版とフル版の違い

| | かんたん版 | フル版(CSV記入手順書.md) |
|---|---|---|
| ファイル形式 | Excel(.xlsx) | CSV |
| 項目数 | 7項目 | 15項目 |
| タグの入力方法 | プルダウンから選ぶだけ | 決まった言葉を手入力 |
| 保存時の形式変換 | 不要(そのまま上書き保存) | 必要(CSV UTF-8を選ぶ) |

まずはかんたん版から試すことをおすすめします。物足りなくなったら、フル版(CSV記入手順書.md)に切り替えられます。

## ① かんたん版ひな形(Excel)をダウンロードする

アプリのホーム画面で「自社データで試す」を選び、「かんたん版ひな形(Excel)をダウンロード」をタップ(クリック)してください。`商品リストかんたん版.xlsx` というファイルがダウンロードされます。

## ② Excelで開く

ダウンロードしたファイルをダブルクリックして開いてください。「商品リスト」というシートに、記入例として仮の商品データが3件入っています。まずはこの例を見て、どんな内容をどこに書けばよいかを確認してください。

## ③ 記入する

サンプル3行を、自社の商品内容に書き換えていってください(行を増やして追加してもかまいません)。列は7つあります。

| 列 | 内容 | 入力方法 |
|---|---|---|
| 商品名 | 商品の名前 | 手入力 |
| 分類 | 商品のジャンル | プルダウンから選ぶ |
| 価格(円) | 価格(税込) | 半角数字だけを入力(例: 3000) |
| ひとこと説明 | 一覧・詳細に出る短い説明 | 手入力 |
| 困りごと1 | この商品で解決できる困りごと | プルダウンから選ぶ(必須) |
| 困りごと2 | 2つ目の困りごと(あれば) | プルダウンから選ぶ(任意) |
| 誰が使う | 利用者 | プルダウンから選ぶ(本人が使う/家族の介護に使う/どちらも) |

セルをクリックすると右側に▼が出るので、そこから選択肢を選んでください。手入力でリストにない言葉を書くと、読み込み時にエラーになります。

**知っておくこと**

- メーカー名・詳しい説明文・仕様・注意点・人気度は、かんたん版では入力を省略します(アプリ側で自動的に埋められます)
- 保険区分はかんたん版では入力できず、全商品「レンタル」扱いで表示されます
- 商品数は最大1,000件までです
- 全部の列が空の行は無視されます(空行があっても大丈夫です)

## ④ 保存する

Excelの「上書き保存」で、そのまま保存してください。**フル版と違い、形式を変換する必要はありません**(.xlsxのまま使えます)。

## ⑤ アプリに読み込む

アプリのホーム画面で「自社データで試す」→「記入したファイルを選ぶ(Excel / CSV)」から、保存したファイルを選択してください。正しく読み込めると「◯件の商品データを読み込みました」と表示され、そのままテストプレイできます。

読み込んだデータは**この端末のブラウザの中だけ**で使われ、どこにも送信・保存されません。画面をリロードすると自動的に元のデモデータに戻ります。

## ⑥ エラーが出たときの読み方

読み込みに失敗すると、「読み込めませんでした(データは変更されていません)」というメッセージと一緒に、エラーの一覧が行番号つきで表示されます。

例: `3行目: 価格 "3,000円" は正の整数ではありません(数字だけを入力してください)`

行番号はExcel上の行番号とそのまま一致します。該当行を直して、もう一度上書き保存・読み込みをやり直してください。エラーが解消されるまで、元のデータ(デモまたは前回読み込んだデータ)はそのまま表示され続けるので、安心して直せます。

## もっと作り込みたくなったら

メーカー名や詳しい商品説明、保険区分、仕様なども登録したい場合は、フル版(`CSV記入手順書.md`)をご覧ください。アプリの「詳しく登録したい方(15項目CSV)」からひな形をダウンロードできます。
