# かんたん版記入手順書

自分の商品データをアプリに読み込ませて、いつでも使えるようにするための、一番かんたんな方法です。プルダウンから選ぶだけで記入できるので、専門知識がなくても進められます。

---

## かんたん版とフル版の違い

| | かんたん版 | フル版(CSV記入手順書.md) |
|---|---|---|
| ファイル形式 | Excel(.xlsx) | CSV |
| 項目数 | 10項目+シーン設定シート | 16項目 |
| タグの入力方法 | プルダウンから選ぶだけ | 決まった言葉を手入力 |
| 保存時の形式変換 | 不要(そのまま上書き保存) | 必要(CSV UTF-8を選ぶ) |

まずはかんたん版から試すことをおすすめします。物足りなくなったら、フル版(CSV記入手順書.md)に切り替えられます。

## ① かんたん版ひな形(Excel)をダウンロードする

アプリのホーム画面で「商品データを読み込む」を選び、「かんたん版ひな形(Excel)をダウンロード」をタップ(クリック)してください。`商品リストかんたん版.xlsx` というファイルがダウンロードされます。

## ② Excelで開く

ダウンロードしたファイルをダブルクリックして開いてください。「商品リスト」と「シーン設定」という2つのシートがあります。「商品リスト」シートには、記入例として仮の商品データが3件入っています。まずはこの例を見て、どんな内容をどこに書けばよいかを確認してください。

## ③ 商品リストシートに記入する

サンプル3行を、自分の商品内容に書き換えていってください(行を増やして追加してもかまいません)。列は10個あります。

| 列 | 内容 | 入力方法 |
|---|---|---|
| 商品名 | 商品の名前 | 手入力(必須) |
| メーカー | 製造メーカー名 | 手入力(任意。空欄は「―」と表示されます) |
| 分類 | 商品のジャンル | プルダウンから選ぶ(必須) |
| 価格(円) | 価格(税込) | 半角数字だけを入力(例: 3000。必須) |
| TAISコード | テクノエイド協会の商品コード | 手入力(任意。わからなければ空欄でかまいません) |
| ひとこと説明 | 一覧・詳細に出る短い説明 | 手入力(必須) |
| 仕様 | 重さ・サイズ等の項目 | 手入力(任意。下記「仕様の書き方」参照) |
| 困りごと1 | この商品で解決できる困りごと | プルダウンから選ぶ(必須) |
| 困りごと2 | 2つ目の困りごと(あれば) | プルダウンから選ぶ(任意) |
| 誰が使う | 利用者 | プルダウンから選ぶ(本人が使う/家族の介護に使う/どちらも。必須) |

セルをクリックすると右側に▼が出るので、そこから選択肢を選んでください。手入力でリストにない言葉を書くと、読み込み時にエラーになります。

### 仕様の書き方

「仕様」の列には、`項目名:値` の形で1行に1項目ずつ書きます。複数の項目を書きたいときは、セルの中で改行(Alt+Enterで改行)して行を分けてください。コロンは半角「:」でも全角「:」でもかまいません。

例(セル内で2行に分けて記入):

```
重さ:290g
高さ調節:71〜94cm(10段階)
```

**知っておくこと**

- 詳しい説明文・注意点・人気度は、かんたん版では入力を省略します(アプリ側で自動的に埋められます)
- 保険区分はかんたん版では入力できず、全商品「レンタル」扱いで表示されます
- 商品数は最大1,000件までです
- 全部の列が空の行は無視されます(空行があっても大丈夫です)

## ④ シーン設定シートで「困りごと」を追加・変更する

「シーン設定」シートには、アプリの「困りごとナビ」やしぼり込みで使う「場面」と「困りごと」の一覧が入っています。ここを書き換えると、商品リストの「困りごと1・2」のプルダウンの選択肢も、アプリの質問の選択肢も、両方まとめて入れ替わります。

- A列=「場面」、B列=「困りごと」。1行に1つの困りごとを書きます
- 同じ場面名を複数行に繰り返して書くことで、1つの場面に複数の困りごとをぶら下げられます
- 新しい場面・困りごとを追加したいときは、一覧の最後に行を足して記入してください
- **困りごとの文言は、シート全体で重複しないようにしてください**(同じ困りごとが2つの場面に入っていると、読み込み時にエラーになります)
- 場面は12種類、困りごとは120行まで登録できます
- 場面・困りごとのどちらかだけが空の行はエラーになります(両方空の行=空行は無視されます)

商品リストシートの「困りごと1・2」のプルダウンは、シーン設定シートのB列を参照しています。シーン設定シートに新しい困りごとを追加したら、商品リストシート側のプルダウンにもすぐに反映されます。

## ⑤ 保存する

Excelの「上書き保存」で、そのまま保存してください。**フル版と違い、形式を変換する必要はありません**(.xlsxのまま使えます)。

## ⑥ アプリに読み込む

アプリのホーム画面で「商品データを読み込む」→「記入したファイルを選ぶ(Excel / CSV)」から、保存したファイルを選択してください。正しく読み込めると「◯件の商品データを読み込みました」と表示され、そのまま使えます。

読み込んだデータは**この端末のブラウザの中だけ**に保存され、外部には一切送信されません。次回アプリを開いたときも、保存したデータが自動的に表示されます。元のデモデータに戻したいときは、「商品データを読み込む」画面の「デモデータに戻す」を押してください(保存されていたデータも削除されます)。

まれに端末の保存容量が足りない等の理由で保存できないことがあります。その場合は読み込み自体は成功しますが、「端末への保存はできませんでした(次回開くと消えます)」という案内が出ます。

## ⑦ エラーが出たときの読み方

読み込みに失敗すると、「読み込めませんでした(データは変更されていません)」というメッセージと一緒に、エラーの一覧が行番号つきで表示されます。

例: `3行目: 価格 "3,000円" は正の整数ではありません(数字だけを入力してください)`

例(シーン設定シート): `シーン設定シート 5行目: 困りごと "ふらつく・転びやすい" が重複しています(困りごとは全体で1つずつにしてください)`

行番号はExcel上の行番号とそのまま一致します。該当行を直して、もう一度上書き保存・読み込みをやり直してください。エラーが解消されるまで、元のデータ(デモまたは前回読み込んだデータ)はそのまま表示され続けるので、安心して直せます。

## もっと作り込みたくなったら

詳しい商品説明や保険区分、人気度なども自分で指定したい場合は、フル版(`CSV記入手順書.md`)をご覧ください。アプリの「詳しく登録したい方(16項目CSV)」からひな形をダウンロードできます。
