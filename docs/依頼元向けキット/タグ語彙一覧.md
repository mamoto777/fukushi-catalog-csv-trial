# タグ語彙一覧

CSVの `genre` / `concernTags` / `sceneTags` / `userTags` に記入できる言葉の一覧です。**ここに載っている言葉と一字一句そのまま**でなければ、読み込み時にエラーになります(コピー&貼り付けでの利用を推奨します)。

`src/data/vocab.json` の内容をそのまま転記したものです(件数: 利用者2件・ジャンル9件・場面7件・困りごと31件)。

---

## 利用者タグ(userTags)

| タグ |
|---|
| 本人が使う |
| 家族の介護に使う |

## ジャンル(genre)

CSVの `genre` 列には「id」を記入してください(表示名ではありません)。

| id | 表示名 |
|---|---|
| walking | 歩行補助 |
| wheelchair | 車いす |
| bed | ベッド・起き上がり |
| mattress | 床ずれ予防・マットレス |
| transfer | 移乗・移動サポート |
| bath | 入浴 |
| toilet | トイレ・排泄 |
| handrail | 手すり・スロープ・段差 |
| watch | 見守り・生活サポート |

## 場面タグ(sceneTags)と困りごとタグ(concernTags)

場面ごとに、対応する困りごとタグをまとめています。`sceneTags` にはこの表の「場面」列の言葉を、`concernTags` にはその場面に属する「困りごと」列の言葉を使ってください(困りごとは場面をまたいで選んでも構いません)。
