# 福祉用具えらびナビ(案件版・CSV読み込み対応)

福祉用具レンタル業の若手社員が、顧客ヒアリングの場で「困りごと」から適切な福祉用具にたどり着き、説明・価格提示までできるスマホ/タブレット用アプリです。デモ版をベースに、**依頼元が自社の商品データ(CSV)をブラウザに読み込んで、実際の商品でテストプレイできる機能**を追加した案件版です。

> **免責**: 標準搭載のデモ用商品・価格・仕様・メーカー名はすべて架空であり、実在のものではありません。自社CSVを読み込んだ場合は、読み込んだ内容がそのまま画面に表示されます。

## 特徴

- **困りごとナビ**: 3つの質問(誰が使う/どの場面/どんな困りごと)に答えるだけで、タグマッチングにより候補商品を提案
- **ジャンル検索**: 9ジャンルから一覧で探せる(どの商品にもホームから3タップ以内)
- **自社データでテストプレイ**: ホーム画面の「自社データで試す」からCSVファイルをブラウザに読み込むだけで、自社の商品を使ってそのままテストプレイできる(下記「自社データでテストプレイする」参照)
- **高齢者に見せられるUI**: 大きな文字(本文18px)・大きなボタン(タップ領域48px以上)・高コントラスト
- **PWA対応**: スマホの「ホーム画面に追加」でアプリのように使える。2回目以降はオフラインでも閲覧可
- **個人情報ゼロ**: 入力フォームなし。回答・読み込んだCSVデータは保存されず、外部送信も一切なし(LLM/AIも不使用)

## 技術構成

| 項目 | 内容 |
|---|---|
| ビルド | Vite 8 + TypeScript |
| UI | React 19 + react-router-dom(HashRouter) |
| スタイル | 素のCSS(CSS変数) |
| テスト | Vitest(マッチングロジックの単体テスト) |
| PWA | 手書き manifest + Service Worker(cache-first・同一オリジンのみ) |
| データ | `src/data/products.json`(仮想100商品をビルドに同梱) |
| ホスティング | GitHub Pages(GitHub Actions で自動デプロイ) |

バックエンド・DB・環境変数・APIキーはありません。

## 自社データでテストプレイする(CSV読み込み)

依頼元が自社の商品データをブラウザに読み込んで、そのままテストプレイできます。外部サーバーへの送信や保存は一切行わず、読み込んだデータはこの端末のブラウザ内だけで使われます。画面をリロードすると自動的に標準のデモデータへ戻ります。

画面写真つきの手順は [使い方ガイド](https://mamoto777.github.io/fukushi-catalog-csv-trial/guide.html) を参照してください(アプリの「自社データで試す」画面からも開けます)。

1. アプリのホーム画面で「自社データで試す」を選ぶ
2. 「ひな形CSVをダウンロード」から `products-template.csv` を取得する
3. Excel等で商品データを記入する(15列。タグ類は決まった語彙のみ使用可)
4. 「CSVファイルを選ぶ」から保存したファイルを読み込む

記入ルール・タグ語彙の一覧・AIに記入を手伝わせる依頼文例は、依頼元向けの資料としてまとめています。

- [CSV記入手順書](docs/依頼元向けキット/CSV記入手順書.md)
- [タグ語彙一覧](docs/依頼元向けキット/タグ語彙一覧.md)
- [Copilot依頼文例](docs/依頼元向けキット/Copilot依頼文例.md)

## 開発者向け: ビルドに同梱するデモデータの差し替え

以下は `src/data/products.json`(ビルドに同梱する標準のデモ商品データ)自体を差し替える開発者向け手順です。依頼元による自社データのテストプレイは上記「自社データでテストプレイする」を参照してください。

商品データはCSVから変換して差し替えられます。

1. `public/products-template.csv` をコピーして `data/products.csv` を作る
2. Excel等で商品を入力する(UTF-8で保存)
   - 複数の値(おすすめ・タグ類)は `|` 区切り
   - 仕様(specs)は `項目名:値|項目名:値` 形式
   - `concernTags` / `sceneTags` / `userTags` は `src/data/vocab.json` にある語彙のみ使える(語彙外はエラーで弾かれる)
   - `genre` は walking / wheelchair / bed / mattress / transfer / bath / toilet / handrail / watch の9種
   - `insurance` は rental(レンタル) / purchase(特定福祉用具販売) / none(保険適用外)
3. 変換を実行する

   ```bash
   npm run data:convert
   ```

   エラーがあれば行番号つきで全件表示されます(その場合ファイルは更新されません)
4. `npm run build` して動作確認 → git push で自動デプロイ

商品画像はジャンル共通のイラスト(`public/images/genre-*.svg`)を使用しています。個別の商品写真に差し替える場合は `public/images/` に画像を置き、CSVのimage列対応を追加する改修が必要です(Phase 2)。

## デプロイ(GitHub Pages)

`main` ブランチへの push で `.github/workflows/deploy.yml` が走り、テスト→ビルド→GitHub Pages 公開まで自動で行われます。

初回のみ、GitHubリポジトリの **Settings → Pages → Source を「GitHub Actions」** に設定してください。

公開URL: `https://mamoto777.github.io/fukushi-catalog-csv-trial/`

## 個人情報の取り扱い

本アプリは以下を**仕様として持ちません**。

- 氏名・年齢等の入力フォーム
- localStorage / Cookie への保存(ナビの回答・読み込んだCSVデータはメモリ上のみで、画面を離れる・リロードすると消えます)
- 外部サーバーへの送信(CSV読み込みはブラウザのFile APIによる端末内処理のみ。Service Workerのキャッシュも同一オリジンのみ)

## ライセンス・注意

知人経由の依頼を想定した試作品です。標準搭載の商品データ・メーカー名はすべて架空です。依頼元が自社CSVを読み込んだ場合、そのデータの内容についての責任は読み込んだ依頼元側にあります(本リポジトリには実データを含みません)。
