# 福祉用具えらびナビ(配布用ベースアプリ)

福祉用具レンタル業の若手社員が、「困りごと」から適切な福祉用具にたどり着き、説明・価格提示までできるスマホ/タブレット用アプリです。まずは知人がまず個人的に使ってみる、配布用のベースアプリという位置づけです。ひな形に自分の商品データ(Excel/CSV)を記入して読み込むと、アプリの中身が丸ごと自分のデータに入れ替わり、そのまま使い続けられます。

> **免責**: 標準搭載のデモ用商品・価格・仕様・メーカー名はすべて架空であり、実在のものではありません。自分の商品データを読み込んだ場合は、読み込んだ内容がそのまま画面に表示されます。

## 特徴

- **困りごとナビ**: 3つの質問(誰が使う/どの場面/どんな困りごと)に答えるだけで、タグマッチングにより候補商品を提案
- **ジャンル検索**: 9ジャンルから一覧で探せる(どの商品にもホームから3タップ以内)。ジャンル内リストでは「場面」でさらに絞り込める
- **商品名からさがす**: 商品名・メーカー名・TAISコードの部分一致でキーワード検索
- **商品データを読み込む**: ホーム画面の「商品データを読み込む」からExcel/CSVファイルをブラウザに読み込むだけで、自分の商品データにまるごと入れ替わる(下記「商品データを読み込む」参照)。読み込んだデータと語彙(場面・困りごと)は端末内(ブラウザのlocalStorage)に保存され、次回開いたときも自動で復元される
- **商品詳細の拡充**: TAISコード表示(入力があるときのみ)・仕様・「似ている商品」(同じ分類+共通の困りごとから自動で最大3件表示)
- **シーンの語彙を自分で入れ替え可能**: かんたん版ひな形の「シーン設定シート」を編集すると、困りごとナビの質問やしぼり込みの選択肢も一緒に入れ替わる
- **高齢者に見せられるUI**: 大きな文字(本文18px)・大きなボタン(タップ領域48px以上)・高コントラスト
- **PWA対応**: スマホの「ホーム画面に追加」でアプリのように使える。2回目以降はオフラインでも閲覧可
- **個人情報ゼロ**: 入力フォームなし。読み込んだデータは端末内(ブラウザのlocalStorage)にのみ保存され、外部送信は一切なし(LLM/AIも不使用)

## 技術構成

| 項目 | 内容 |
|---|---|
| ビルド | Vite 8 + TypeScript |
| UI | React 19 + react-router-dom(HashRouter) |
| スタイル | 素のCSS(CSS変数) |
| テスト | Vitest(検証ロジック・マッチング・検索・類似商品抽出等の単体テスト) |
| PWA | 手書き manifest + Service Worker(cache-first・同一オリジンのみ) |
| データ | `src/data/products.json`(仮想100商品をビルドに同梱)+ 読み込んだデータはブラウザのlocalStorageに保存 |
| ホスティング | GitHub Pages(GitHub Actions で自動デプロイ) |

バックエンド・DB・環境変数・APIキーはありません。

## 商品データを読み込む(Excel/CSV読み込み)

自分の商品データをブラウザに読み込んで、そのまま使い続けられます。外部サーバーへの送信は一切行わず、読み込んだデータと語彙はこの端末のブラウザ内(localStorage)だけに保存されます。次回アプリを開いたときも自動的に復元され、「デモデータに戻す」でいつでも標準のデモデータに戻せます(保存データも削除されます)。

画面写真つきの手順は [使い方ガイド](https://mamoto777.github.io/fukushi-catalog-csv-trial/guide.html) を参照してください(アプリの「商品データを読み込む」画面からも開けます)。

読み込み方法は2種類あります。

**かんたん版(Excel・10項目+シーン設定シート・プルダウン選択、おすすめ)**

1. アプリのホーム画面で「商品データを読み込む」を選ぶ
2. 「かんたん版ひな形(Excel)をダウンロード」から `products-template-simple.xlsx` を取得する
3. Excelで開き、「商品リスト」シートに記入する(分類・困りごと・誰が使うはプルダウンから選ぶだけ。メーカー・TAISコード・仕様は手入力・任意。形式変換不要、そのまま上書き保存)。「シーン設定」シートを編集すると、場面・困りごとの語彙自体を入れ替えられる
4. 「記入したファイルを選ぶ(Excel / CSV)」から保存したファイルを読み込む

**フル版(CSV・16項目・手入力)**

1. 「商品データを読み込む」画面の「詳しく登録したい方(16項目CSV)」を開く
2. 「ひな形CSVをダウンロード」から `products-template.csv` を取得する
3. Excel等で商品データを記入する(16列。TAISコードは任意・タグ類は決まった語彙のみ使用可。保存時は「CSV UTF-8」形式)
4. 「記入したファイルを選ぶ(Excel / CSV)」から保存したファイルを読み込む

記入ルール・タグ語彙の一覧・AIに記入を手伝わせる依頼文例は、以下の資料としてまとめています。

- [かんたん版記入手順書](docs/依頼元向けキット/かんたん版記入手順書.md)
- [CSV記入手順書](docs/依頼元向けキット/CSV記入手順書.md)
- [タグ語彙一覧](docs/依頼元向けキット/タグ語彙一覧.md)
- [Copilot依頼文例](docs/依頼元向けキット/Copilot依頼文例.md)

## 開発者向け: ビルドに同梱するデモデータの差し替え

以下は `src/data/products.json`(ビルドに同梱する標準のデモ商品データ)自体を差し替える開発者向け手順です。利用者による自分の商品データの読み込みは上記「商品データを読み込む」を参照してください。

商品データはCSVから変換して差し替えられます。

1. `src/assets/products-template.csv` をコピーして `data/products.csv` を作る
2. Excel等で商品を入力する(UTF-8で保存)
   - 複数の値(おすすめ・タグ類)は `|` 区切り
   - 仕様(specs)は `項目名:値|項目名:値` 形式
   - `concernTags` / `sceneTags` / `userTags` は `src/data/vocab.json` にある語彙のみ使える(語彙外はエラーで弾かれる)
   - `genre` は walking / wheelchair / bed / mattress / transfer / bath / toilet / handrail / watch の9種
   - `insurance` は rental(レンタル) / purchase(特定福祉用具販売) / none(保険適用外)
   - `taisCode` は任意(空文字可)
3. 変換を実行する

   ```bash
   npm run data:convert
   ```

   エラーがあれば行番号つきで全件表示されます(その場合ファイルは更新されません)
4. `npm run build` して動作確認 → git push で自動デプロイ

商品画像はジャンル共通のイラスト(`src/assets/images/genre-*.svg`、`src/assets/genreIcons.ts` でジャンルidにマップ)を使用しています。個別の商品写真に差し替える場合は画像を追加し、CSVのimage列対応を追加する改修が必要です(Phase 2)。

## デプロイ(GitHub Pages)

`main` ブランチへの push で `.github/workflows/deploy.yml` が走り、テスト→ビルド→GitHub Pages 公開まで自動で行われます。

## オフライン版(ネット不要のパッケージ)

インターネット接続なしで動く配布用パッケージを作れます。GitHub Pages版とは別のビルド系統で、Pages版のビルド・デプロイには影響しません。

```bash
npm run build:offline                    # dist-offline/index.html(JS/CSS/画像/ひな形を1ファイルに埋め込み)を生成
python scripts/package_offline.py        # release-offline/ にzip一式を生成
```

出力される `release-offline/福祉用具えらびナビ_オフライン版.zip` の中身:

- `アプリ.html` — ダブルクリックで開くだけで動く単一HTML(ネット不要)
- `使い方ガイド.html` — 画面写真つきの使い方ガイド

データの扱いはPages版と同じで、読み込んだ商品データはこの端末のブラウザ内(localStorage)にのみ保存され、外部送信は一切ありません。オフライン版はService Worker(通信の肩代わり機能)を登録しません(ネット不要のため元々不要)。

設計の詳細は [docs/design-offline.md](docs/design-offline.md) を参照してください。

初回のみ、GitHubリポジトリの **Settings → Pages → Source を「GitHub Actions」** に設定してください。

公開URL: `https://mamoto777.github.io/fukushi-catalog-csv-trial/`

## 個人情報の取り扱い

本アプリは以下を**仕様として持ちません**。

- 氏名・年齢等の入力フォーム
- 外部サーバーへの送信(読み込みはブラウザのFile APIによる端末内処理のみ。Service Workerのキャッシュも同一オリジンのみ)

読み込んだ商品データ・語彙は、この端末のブラウザのlocalStorage(端末内の保存領域)にのみ保存されます。外部には一切送信されません。「デモデータに戻す」を押すか、ブラウザの設定でサイトデータを削除すると消去できます。

## ライセンス・注意

知人経由の配布を想定した試作品です。標準搭載の商品データ・メーカー名はすべて架空です。自分の商品データを読み込んだ場合、そのデータの内容についての責任は読み込んだ利用者側にあります(本リポジトリには実データを含みません)。
